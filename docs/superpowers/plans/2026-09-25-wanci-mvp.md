# Wanci MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Wanci MVP — an Android screen-time intervention app that tracks per-app foreground usage via an accessibility service and shows an overlay intervention once a user-set daily limit is exceeded.

**Architecture:** Kotlin Multiplatform. `shared` (commonMain) holds UI (Compose Multiplatform), domain, data (Room KMP), and a pure `MonitoringCore`; `androidApp` holds Android bindings: `MonitoringAccessibilityService` (thin adapter feeding `MonitoringCore`), `UsageStatsReader` (reconcile safety net via `UsageStatsManager`), and `OverlayManager` (renders the shared `OverlayScreen` in a `SYSTEM_ALERT_WINDOW` window). Manual DI. Tech spike (accessibility → usage → overlay) is gated before any substantive UI build.

**Tech Stack:** Kotlin 2.4.20, Compose Multiplatform 1.12.1, AGP 9.1.1, Room 2.8.5 (KMP, KSP), navigation-compose 2.9.2 (JetBrains, latest stable; 2.9.8 does not exist), kotlinx-coroutines 1.10.2, SQLite bundled 2.6.2.

## Global Constraints

- Package root: `com.septaalfauzan.wanci`. Shared code lives in `shared/src/commonMain/kotlin/com/septaalfauzan/wanci/`; Android bindings in `androidApp/src/main/kotlin/com/septaalfauzan/wanci/`.
- minSdk 28, targetSdk 37, compileSdk 37, AGP 9.1.1, Kotlin 2.4.20, JVM target 11.
- Room version `androidx.room:room-runtime` / `room-compiler` = `2.8.5`. SQLite: iOS uses sqlite-bundled = `2.6.2`; **Android uses the framework driver (`androidx.sqlite:sqlite-framework` = `2.6.2`, `FrameworkSQLiteOpenHelperFactory`) instead of the bundled driver** — the bundled driver's native lib cannot load on the JVM host test runner (Robolectric), and the framework driver works under Robolectric's Android sqlite shadows + on real devices. KSP plugin = `2.3.11` (if 2.3.11 mismatches Kotlin 2.4.20, use 2.3.10 — same feature set).
- navigation-compose (JetBrains) = `2.9.2`; kotlinx-coroutines-core = `1.10.2`. Host-test deps: kotlinx-coroutines-test = `1.10.2`, Robolectric = `4.17` (latest stable) for Android host-test target (`androidHostTest`), with `testOptions { unitTests { isIncludeAndroidResources = true } }` in shared. Robolectric provides the Android Context that `Room.databaseBuilder` needs on the plain JVM host runner; DB tests seed `AndroidAppContextHolder.context` from `ApplicationProvider`.
- App working name **Wanci**. UI theme is monochrome only (white-on-black / black-on-white inverse). No gradients, shadows, or non-monochrome accents.
- `PackageName` is the stable app identity. Usage is keyed by `packageName + ISO date (yyyy-MM-dd)`.
- Wanci must never monitor its own package.
- No foreground service, no battery-optimization request, no backend, no notifications in MVP (notifications plan is a separate doc).
- DAO suspend functions + `Flow` return types only (Room 2.8 KMP). `exportSchema = false` (no migrations).
- Backup: every task ends with a commit; commit messages Conventional Commits style, subject ≤ 50 chars.
- Host tests run with: `./gradlew :shared:testAndroidHostTest`. Android build check: `./gradlew :androidApp:assembleDebug`.

> **Amendment (approved in review):** `TodayKey.dateFlow()` was added so `observeTodayUsage` stays reactive across midnight. Android actual: `MutableStateFlow(LocalDate.now().toString())` recomputed via a delayed coroutine loop to next midnight; iOS actual: same with `NSDateFormatter`/`NSCalendar`. `observeTodayUsage(packageName)` is `todayKey.dateFlow().flatMapLatest { date -> dailyUsageDao.observeForDate(date).map { list -> ... } }`.

```kotlin
package com.septaalfauzan.wanci.data.local

import android.content.Context
import androidx.room.Room
import androidx.sqlite.driver.bundled.BundledSQLiteDriver
import java.time.LocalDate

object AndroidAppContextHolder {
    lateinit var context: Context

actual fun createWanciDatabase(nameOverride: String?): WanciDatabase {
    val name = nameOverride ?: WanciDatabase.DB_NAME
    return Room.databaseBuilder(AndroidAppContextHolder.context, WanciDatabase::class.java, name)
```

```kotlin
import androidx.room.Room
import androidx.sqlite.driver.bundled.BundledSQLiteDriver
import kotlinx.cinterop.ExperimentalForeignApi
```

```kotlin
package com.septaalfauzan.wanci.data.repository

import com.septaalfauzan.wanci.data.local.DailyUsageDao
import com.septaalfauzan.wanci.data.local.MonitoredAppDao
import com.septaalfauzan.wanci.data.local.SyncStateDao
import com.septaalfauzan.wanci.data.local.TodayKey
import com.septaalfauzan.wanci.data.local.entity.DailyUsageEntity
import com.septaalfauzan.wanci.data.local.entity.SyncStateEntity
import com.septaalfauzan.wanci.domain.model.MonitoredApp
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.combine
import kotlinx.coroutines.flow.flowOf

class ScreenTimeRepositoryImpl(
    private val monitoredAppDao: MonitoredAppDao,
    private val dailyUsageDao: DailyUsageDao,
    private val syncStateDao: SyncStateDao,
    private val todayKey: TodayKey,
) : ScreenTimeRepository {

    override fun observeMonitoredApps(): Flow<List<MonitoredApp>> {
        val apps = monitoredAppDao.observeAll()
        return todayKey.dateFlow().flatMapLatest { date ->
            val usage = dailyUsageDao.observeForDate(date)
            combine(apps, usage) { appEntities, usageEntities ->
                val usageByPackage = usageEntities.associateBy { it.packageName }
                appEntities.map { it.toDomain(usageByPackage[it.packageName]?.usageMinutes ?: 0L) }
            }
        }
    }

    override fun observeTodayUsage(packageName: String): Flow<Long> =
        todayKey.dateFlow().flatMapLatest { date ->
            dailyUsageDao.observeForDate(date)
                .map { list -> list.firstOrNull { it.packageName == packageName }?.usageMinutes ?: 0L }
        }

    override suspend fun getMonitoredApp(packageName: String): MonitoredApp? =
        monitoredAppDao.getByPackage(packageName)?.toDomain(0L)

    override suspend fun getTodayUsage(packageName: String, date: String): Long =
        dailyUsageDao.getUsage(packageName, date) ?: 0L

    override suspend fun addMonitoredApp(packageName: String, appName: String, dailyLimitMinutes: Int): Boolean {
        val now = System.currentTimeMillis()
        val id = monitoredAppDao.insert(
            com.septaalfauzan.wanci.data.local.entity.MonitoredAppEntity(
                packageName = packageName,
                appName = appName,
                dailyLimitMinutes = dailyLimitMinutes,
                createdAt = now,
                updatedAt = now,
            )
        )
        return id != -1L
    }

    override suspend fun updateDailyLimit(packageName: String, dailyLimitMinutes: Int) {
        monitoredAppDao.updateLimit(packageName, dailyLimitMinutes, System.currentTimeMillis())
    }

    override suspend fun setMonitoringEnabled(packageName: String, enabled: Boolean) {
        monitoredAppDao.setEnabled(packageName, enabled, System.currentTimeMillis())
    }

    override suspend fun removeMonitoredApp(packageName: String) {
        monitoredAppDao.deleteByPackage(packageName)
    }

    override suspend fun recordUsage(packageName: String, deltaMinutes: Long, date: String) {
        val now = System.currentTimeMillis()
        if (dailyUsageDao.insertOrIgnore(DailyUsageEntity(packageName, date, deltaMinutes, now)) == -1L) {
            dailyUsageDao.addDelta(packageName, date, deltaMinutes, now)
        }
    }

    override suspend fun reconcileDailyUsage(deltaMinutesByPackage: Map<String, Long>, date: String) {
        deltaMinutesByPackage.forEach { (packageName, statsMinutes) ->
            val now = System.currentTimeMillis()
            if (dailyUsageDao.insertOrIgnore(DailyUsageEntity(packageName, date, statsMinutes, now)) == -1L) {
                dailyUsageDao.raiseToAtLeast(packageName, date, statsMinutes, now)
            }
        }
    }

    override suspend fun getSyncValue(key: String): String? = syncStateDao.get(key)

    override fun observeSyncValue(key: String): Flow<String?> =
        syncStateDao.observe(key).map { it?.value }

    override suspend fun putSyncValue(key: String, value: String) {
        syncStateDao.put(SyncStateEntity(key, value))
    }

    private fun com.septaalfauzan.wanci.data.local.entity.MonitoredAppEntity.toDomain(todayUsageMinutes: Long) =
        MonitoredApp(
            id = id,
            packageName = packageName,
            appName = appName,
            dailyLimitMinutes = dailyLimitMinutes,
            enabled = enabled,
            createdAt = createdAt,
            updatedAt = updatedAt,
            todayUsageMinutes = todayUsageMinutes,
        )
}
```

```kotlin
package com.septaalfauzan.wanci.monitoring

import com.septaalfauzan.wanci.data.local.TodayKey
import com.septaalfauzan.wanci.data.repository.ScreenTimeRepository

class MonitoringCore(
    private val repository: ScreenTimeRepository,
    private val todayKey: TodayKey,
    private val selfPackageName: String,
) {
    data class OverlayDecision(
        val packageName: String,
        val appName: String,
        val usageMinutes: Long,
        val limitMinutes: Int,
    )

    private var lastPackage: String? = null
    private var lastEventTime: Long = 0L
    private val triggeredByDate = mutableMapOf<String, MutableSet<String>>()

    suspend fun onForegroundChange(packageName: String?, eventTimeMillis: Long): OverlayDecision? {
        val previousPackage = lastPackage
        val previousTime = lastEventTime

        lastPackage = packageName
        if (packageName != null) lastEventTime = eventTimeMillis

        if (previousPackage == null || previousPackage == packageName) return null
        if (previousPackage == selfPackageName) return null

        val elapsedMillis = (eventTimeMillis - previousTime).coerceAtLeast(0L)
        val deltaMinutes = elapsedMillis / 60_000L

        val app = repository.getMonitoredApp(previousPackage)
        if (app == null || !app.enabled) return null

        val date = todayKey.todayIso()
        if (deltaMinutes >= 1) {
            repository.recordUsage(previousPackage, deltaMinutes, date)
        }

        val usage = repository.getTodayUsage(previousPackage, date)
        if (!LimitChecker.exceeds(usage, app.dailyLimitMinutes)) return null

        val triggered = triggeredByDate.getOrPut(date) { mutableSetOf() }
        if (previousPackage in triggered) return null
        triggered += previousPackage
        return OverlayDecision(
            packageName = previousPackage,
            appName = app.appName,
            usageMinutes = usage,
            limitMinutes = app.dailyLimitMinutes,
        )
    }

    fun onOverlayDismissed(packageName: String) {
        val date = todayKey.todayIso()
        triggeredByDate[date]?.remove(packageName)
    }

    fun resetDay() {
        val today = todayKey.todayIso()
        triggeredByDate.keys.removeIf { it != today }
    }
}
```

```kotlin
package com.septaalfauzan.wanci.monitoring

import android.content.Context
import android.content.Intent
import android.graphics.PixelFormat
import android.graphics.Color
import android.view.Gravity
import android.view.ViewGroup
import android.view.WindowManager
import androidx.compose.material3.MaterialTheme
import androidx.compose.runtime.CompositionLocalProvider
import androidx.compose.ui.platform.ComposeView
import androidx.lifecycle.Lifecycle
import androidx.lifecycle.LifecycleOwner
import androidx.lifecycle.LifecycleRegistry
import androidx.lifecycle.setViewTreeLifecycleOwner
import com.septaalfauzan.wanci.presentation.overlay.OverlayScreen
import kotlinx.coroutines.CoroutineScope

class OverlayManager(
    private val context: Context,
    private val core: MonitoringCore,
    private val scope: CoroutineScope,
) {

    private class OverlayLifecycleOwner : LifecycleOwner {
        private val registry = LifecycleRegistry(this)
        init {
            registry.currentState = Lifecycle.State.RESUMED
        }
        override val lifecycle: Lifecycle get() = registry
    }

    private val lifecycleOwner = OverlayLifecycleOwner()
    private val windowManager = context.getSystemService(Context.WINDOW_SERVICE) as WindowManager
    private var overlayView: ComposeView? = null
    private var visiblePackage: String? = null

    fun show(decision: MonitoringCore.OverlayDecision) {
        if (overlayView != null) return
        val params = WindowManager.LayoutParams(
            ViewGroup.LayoutParams.MATCH_PARENT,
            ViewGroup.LayoutParams.MATCH_PARENT,
            WindowManager.LayoutParams.TYPE_APPLICATION_OVERLAY,
            WindowManager.LayoutParams.FLAG_LAYOUT_IN_SCREEN,
            PixelFormat.TRANSLUCENT,
        ).apply {
            gravity = Gravity.TOP or Gravity.START
        }
        val view = ComposeView(context).apply {
            setBackgroundColor(Color.WHITE)
            setViewTreeLifecycleOwner(lifecycleOwner)
            setContent {
                OverlayScreen(
                    appName = decision.appName,
                    usageMinutes = decision.usageMinutes,
                    limitMinutes = decision.limitMinutes,
                    onLeave = { leaveApp() },
                    onManage = { openWanci(decision.packageName) },
                )
            }
        }
        try {
            windowManager.addView(view, params)
        } catch (_: Exception) {
            return
        }
        overlayView = view
        visiblePackage = decision.packageName
    }

    fun dismiss() {
        val view = overlayView ?: return
        visiblePackage?.let { core.onOverlayDismissed(it) }
        visiblePackage = null
        overlayView = null
        try {
            windowManager.removeView(view)
        } catch (_: Exception) {
        }
    }

    private fun leaveApp() {
        dismiss()
        val home = Intent(Intent.ACTION_MAIN).apply {
            addCategory(Intent.CATEGORY_HOME)
            flags = Intent.FLAG_ACTIVITY_NEW_TASK
        }
        context.startActivity(home)
    }

    private fun openWanci(packageName: String) {
        dismiss()
        val intent = context.packageManager.getLaunchIntentForPackage(context.packageName)
            ?: Intent(Intent.ACTION_MAIN).apply {
                setPackage(context.packageName)
                addCategory(Intent.CATEGORY_LAUNCHER)
            }
        intent.flags = Intent.FLAG_ACTIVITY_NEW_TASK or Intent.FLAG_ACTIVITY_CLEAR_TOP
        intent.putExtra("com.septaalfauzan.wanci.extra.PACKAGE", packageName)
        context.startActivity(intent)
    }
}
```

```kotlin
package com.septaalfauzan.wanci.monitoring

import android.accessibilityservice.AccessibilityService
import android.view.accessibility.AccessibilityEvent
import com.septaalfauzan.wanci.WanciApplication
import java.util.concurrent.atomic.AtomicBoolean
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.launch

class MonitoringAccessibilityService : AccessibilityService() {

    private var ready: AtomicBoolean = AtomicBoolean(false)

    private val appScope: CoroutineScope
        get() {
            val app = application as? WanciApplication ?: throw IllegalStateException("Missing WanciApplication")
            return app.container.scope
        }

    override fun onServiceConnected() {
        super.onServiceConnected()
        ready.set(true)
    }

    override fun onAccessibilityEvent(event: AccessibilityEvent?) {
        if (!ready.get()) return
        if (event == null) return
        if (event.eventType != AccessibilityEvent.TYPE_WINDOW_STATE_CHANGED) return
        val packageName = event.packageName?.toString() ?: return
        val scope = appScope
        val container = (application as WanciApplication).container
        scope.launch {
            val decision = container.core.onForegroundChange(packageName, event.eventTime)
            if (decision != null) {
                container.overlayManager.show(decision)
            }
        }
    }

    override fun onInterrupt() {}
}
```

```kotlin
import android.accessibilityservice.AccessibilityServiceInfo
import android.app.AppOpsManager
import android.content.Context
import android.provider.Settings
import android.view.accessibility.AccessibilityManager
import com.septaalfauzan.wanci.domain.PermissionStatus

object PermissionChecks {
    fun status(context: Context): PermissionStatus = PermissionStatus(
        usageAccess = hasUsageAccess(context),
        overlay = Settings.canDrawOverlays(context),
        accessibility = hasAccessibility(context),
    )

    private fun hasUsageAccess(context: Context): Boolean {
        val appOps = context.getSystemService(Context.APP_OPS_SERVICE) as AppOpsManager
        val mode = appOps.checkOpNoThrow(
            AppOpsManager.OPSTR_GET_USAGE_STATS,
            android.os.Process.myUid(),
            context.packageName,
        )
        return mode == AppOpsManager.MODE_ALLOWED
    }

    private fun hasAccessibility(context: Context): Boolean {
        val am = context.getSystemService(Context.ACCESSIBILITY_SERVICE) as AccessibilityManager
        val expected = context.packageName + "/" + com.septaalfauzan.wanci.monitoring.MonitoringAccessibilityService::class.java.name
        return am.getEnabledAccessibilityServiceList(AccessibilityServiceInfo.FEEDBACK_ALL_MASK)
            .any { it.resolveInfo.serviceInfo.packageName == context.packageName }
    }
}
```

```kotlin
data class OnboardingUiState(

    val permissionStatus: PermissionStatus = PermissionStatus(false, false, false),
    val saving: Boolean = false,

class OnboardingViewModel(
    private val useCases: WanciUseCases,
    private val permissionStatusProvider: PermissionStatusProvider,
    private val permissionNavigator: PermissionNavigator,
) : ViewModel() {

    private val _state = MutableStateFlow(OnboardingUiState())
    val state: StateFlow<OnboardingUiState> = _state.asStateFlow()

        _state.value = _state.value.copy(permissionStatus = permissionStatusProvider.status())

    fun requestAccessibility() = permissionNavigator.openAccessibility()

    fun completeOnboarding(onDone: () -> Unit) {
        viewModelScope.launch {
            _state.value = _state.value.copy(saving = true)
            useCases.putSyncValue("onboardingComplete", "true")
            onDone()
        }
    }
```

```kotlin
import android.content.Context

import com.septaalfauzan.wanci.domain.InstalledAppsProvider

class InstalledAppsProviderAndroid(private val context: Context) : InstalledAppsProvider {
    override fun getInstalledApps(): List<InstalledApp> {
        val pm = context.packageManager
        val intent = Intent(Intent.ACTION_MAIN).addCategory(Intent.CATEGORY_LAUNCHER)
        return pm.queryIntentActivities(intent, PackageManager.ResolveInfoFlags.of(0))
            .mapNotNull { ri ->
                val label = ri.activityInfo?.loadLabel(pm)?.toString() ?: return@mapNotNull null
                val pkg = ri.activityInfo.packageName
                if (pkg == context.packageName) return@mapNotNull null
                InstalledApp(packageName = pkg, appName = label)
            }
            .distinctBy { it.packageName }
            .sortedBy { it.appName }
    }
}
```

```kotlin
package com.septaalfauzan.wanci.monitoring

import android.app.usage.UsageEvents
import android.app.usage.UsageStatsManager
import android.content.Context
import com.septaalfauzan.wanci.data.repository.ScreenTimeRepository
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.flow.first
import kotlinx.coroutines.launch

class UsageStatsReader(
    private val context: Context,
) {
    fun queryForegroundMinutes(fromEpoch: Long, toEpoch: Long): Map<String, Long> {
        val usm = context.getSystemService(Context.USAGE_STATS_SERVICE) as UsageStatsManager
        val events = usm.queryEvents(fromEpoch, toEpoch)
        val isForeground = mutableMapOf<String, Boolean>()
        val lastStamp = mutableMapOf<String, Long>()
        val totals = mutableMapOf<String, Long>()

        val event = UsageEvents.Event()
        while (events.hasNextEvent()) {
            events.getNextEvent(event)
            val pkg = event.packageName ?: continue
            val stamp = event.timeStamp
            when (event.eventType) {
                UsageEvents.Event.MOVE_TO_FOREGROUND -> {
                    isForeground[pkg] = true
                    lastStamp[pkg] = stamp
                }
                UsageEvents.Event.MOVE_TO_BACKGROUND, UsageEvents.Event.ACTIVITY_STOPPED -> {
                    if (isForeground[pkg] == true) {
                        totals[pkg] = (totals[pkg] ?: 0L) + (stamp - (lastStamp[pkg] ?: fromEpoch))
                        isForeground[pkg] = false
                    }
                }
            }
        }
        return totals.mapValues { (pkg, ms) -> ms / 60_000L }
    }

    suspend fun reconcile(repository: ScreenTimeRepository, todayKey: () -> String) {
        val now = System.currentTimeMillis()
        val marker = repository.getSyncValue("lastReconcileEpochMillis")?.toLongOrNull() ?: (now - 24 * 3600_000L)
        if (now - marker < 60_000L) return
        val deltas = queryForegroundMinutes(marker, now)
        repository.reconcileDailyUsage(deltas, todayKey())
        repository.putSyncValue("lastReconcileEpochMillis", now.toString())
    }
}
```
